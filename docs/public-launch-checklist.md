# Public launch checklist

- [ ] Set the repository description to: **Local-first fantasy-football decision system with
  live Sleeper state, deterministic analytics, seeded wait-cost simulation, and a read-only MCP
  copilot.**
- [ ] Add topics: `fantasy-football`, `sleeper`, `python`, `mcp`, `codex`, `ai-agents`, `duckdb`,
  `sports-analytics`, `monte-carlo`, and `decision-support`.
- [ ] Upload a social preview image that shows the architecture or one clean recommendation plus
  survival result; exclude account, league, and local-path details.
- [ ] Add the final video/GIF URL to the README Demo section and verify it while signed out.
- [ ] Pin the repository on the GitHub profile.
- [ ] Confirm the default branch contains this hardening patch and its CI checks are green.
- [ ] Consider a small annotated `v0.1.0` release/tag after choosing a license and verifying the
  clean-clone instructions from a fresh directory.
- [ ] Review GitHub's public file list for databases, `.env`, `.codex/config.toml`, raw exports,
  caches, and personal screenshots before announcing it.
